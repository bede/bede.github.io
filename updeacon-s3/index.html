updeacon-s3

Securely filter and upload DNA sequences in fasta/fastq format directly to S3 object storage. Runs Deacon in the browser to deplete human sequences prior to upload. Files are uploaded to a timestamped path prefix. Nested directory structures are preserved.

Usage
  1. Press 'Download index' or wait for the cached panhuman-1 index to load.
  2. Drag & drop fasta/fastq files you wish to upload or a directory containing them. Illumina R1/R2 files are paired automatically.
  3. Choose an upload name and press 'Filter & upload' or 'Filter only'.
