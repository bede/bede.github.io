updeacon-s3 alpha

Securely dehost and upload DNA sequences in fasta/fastq format directly to S3 object storage. Runs Deacon in the browser to deplete human sequences prior to upload. FASTQ files are uploaded to a timestamped path prefix. Nested directory structures are preserved.

Usage
  1. Press 'Download index', or wait for the cached copy of panhuman-1 to load.
  2. Drag & drop fasta/fastq files you wish to upload, or a directory containing them. Illumina R1/R2 files are paired automatically.
  3. Choose an upload name and then press 'Filter & upload' or 'Filter only'.
